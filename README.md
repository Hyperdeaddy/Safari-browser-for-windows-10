# Браузер Safari для Windows 10/11

> Создал браузер Safari в стиле OS 27 со всеми его функциями на основе старенького движка JPHP (DevelNext) (Сам браузер еще в разработке, но скоро доделаю)

## ✨ Особенности (Features)
- Цвет окна меняется в зависимости от отображаемого сайта
- Почти все функции перенесены прямиком из Safari OS 27
- Может заменить вам скучный браузер
